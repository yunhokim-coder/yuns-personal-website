Ongoing project · 2026

I’m on the Next Level in Education

A web game version of my classroom academic-motivation program. Students meet their learning character, find the energy behind a goal, name the “Black Mamba” that gets in the way of studying, and choose strategies to beat it. It is built so any teacher can run it in a single class period, starting with small rural schools that have no school counselor on site.
